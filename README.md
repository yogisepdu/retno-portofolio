# Retno Portfolio

Portfolio website untuk **Retno Anggraini**, dibangun dengan Next.js, TypeScript, Tailwind CSS, Framer Motion, dan Lucide React.

## Requirement

- Node.js 20.9+ direkomendasikan
- npm

## Instalasi

```bash
npm install
npm run dev
```

Buka:

```text
http://localhost:3000
```

## Build production

```bash
npm run lint
npm run build
npm run start
```

## Catatan

Isi portofolio disusun berdasarkan CV Retno Anggraini yang diberikan. Foto, screenshot proyek, sertifikat, dan tautan demo proyek dapat ditambahkan kemudian tanpa mengubah arsitektur utama.

## Deployment

Project siap dideploy ke Vercel atau platform hosting Next.js lainnya.
